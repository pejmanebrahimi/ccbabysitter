    CC Babysitter docs

    CC Babysitter keeps Claude Code sessions alive and reachable. If you're new to it, start with the tutorial.

    • TutorialBabysit your first session

      Install CC Babysitter, babysit a session, close its terminal on purpose and pick the session up from your phone. It takes about ten minutes.

    • How-to guideRun it on a server

      Keep sessions alive on a Linux server you reach over SSH, through SSH drops and reboots.

    • How-to guideStart at login

      Check, turn on or turn off starting CC Babysitter when you log in, so babysat sessions come back after a restart.

    • How-to guideUse it from Claude Code

      Install the plugin, then babysit a session, check on it or open the page by asking in your own words.

    • How-to guideStop or remove it

      Stop babysitting a session, quit CC Babysitter for now, stop it starting at login, or remove it completely.

    • ReferenceCommands

      Every command, with its flags, output, JSON and exit codes.
