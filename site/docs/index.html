CC Babysitter docs

CC Babysitter keeps Claude Code sessions alive and reachable. These pages show you how to use it, and each page does one job.

  • TutorialBabysit your first session

    Install CC Babysitter, babysit a session, close its terminal on purpose and pick the session up from your phone. It takes about ten minutes.

For now the docs have this one tutorial. The README on GitHub (opens in a new tab) covers the rest, such as running on a server, the Claude Code plugin and the settings. And ccbabysitter --help lists every command.
