    How-to guide

    Use CC Babysitter from Claude Code

    With the CC Babysitter plugin, you can babysit the session you're in by asking for it, without leaving Claude Code.

    The plugin works in Claude Code only, on the computer CC Babysitter runs on. It drives CC Babysitter's own commands, so everything it does also shows on the page and in its Activity panel.

    CC Babysitter itself doesn't need to be installed first. If it isn't, the plugin gives you the one command that installs and starts it when you first ask it to do something.

    Ask in your own words

    Say what you want, in any language. For example:

    • "babysit this session", or /ccbabysitter:babysit
    • "babysit the api session", or /ccbabysitter:babysit api
    • "is this session babysat?"
    • "stop babysitting it"
    • "open the babysitter page"
    • "why was my session restarted last night?"

    Answers about how CC Babysitter works come from its help and README, which are part of the plugin. For a name that fits more than one session, you get a list of them to choose from.

    The plugin never runs a command whose output holds the page's key, so the key never ends up in your chat. To show the page, it runs ccbabysitter open, which opens it in your browser.

    When CC Babysitter isn't running

    If CC Babysitter isn't installed or isn't running, the plugin says so. It gives you the command to run in your terminal app. It never runs that command itself, since its output would bring the page's key into the chat. Run it, then tell the plugin you're done, and it carries on with what you asked.

    What it asks before doing

    Babysitting, unbabysitting, trying a stuck session again, and opening the page happen right away. So do the commands that only read, such as listing sessions or reading the activity log. The first time in a conversation, it may also offer to open the page.

    It asks you on a card before it stops a background copy, changes a setting or quits CC Babysitter. It also asks before it sets CC Babysitter up as a service on Linux, or stops it and turns off start at login. It never resets CC Babysitter or removes it completely: for those it explains what they delete and gives you the command to run yourself.
