Tutorial

Babysit your first session

In this tutorial you install CC Babysitter, babysit a Claude Code session, close its terminal on purpose, and pick the session up from your phone. It takes about ten minutes.

Before you start

You need:

  • A Mac, a Windows PC or a Linux desktop. A server you reach over SSH works too, with its own steps in the README.
  • Claude Code 2.1.275 or later, logged in. claude --version tells you which version you have.
  • The Claude app on your phone, signed in to the same account.

Start it

Run CC Babysitter:

CC Babysitter starts in the background and opens its page in your browser, then gives you the terminal back. From now on it also starts by itself when you log in.

The page lists every Claude Code session on this computer, whatever app it runs in. Sessions you babysit go at the top, under Babysat, which is empty for now.

The page's address includes a key that only your account can read. If you close the tab, ccbabysitter open opens it again.

Start a session

Open a new terminal window, go to one of your project folders and start Claude Code:

Ask it something small, such as what's in the folder. A session needs at least one message before there's anything to bring back.

Then switch on Remote Control, so you can reach the session from your phone:

Back on the page, the session shows up under Running within a few seconds.

Babysit it

Press Babysit on the session's row. The dialog says what babysitting does. CC Babysitter keeps the computer awake, and if the terminal closes, the session carries on in the background with Remote Control.

Press Babysit in the dialog. The session moves to the Babysat list, and its card says Watching in a terminal window.

On a laptop, keep the lid open: keeping the computer awake doesn't stop a closed lid from putting it to sleep.

Close the terminal

Now the test. Close the terminal window the session runs in, the way an app update or a crash would.

Within a few seconds the card changes. If CC Babysitter started less than 90 seconds ago, it first waits out those 90 seconds, so apps that restore their own sessions go first.

The card's panel now says Kept alive while you were away, with the time the terminal closed and a trail from Terminal to Background. The session is running again in the background, with Remote Control on.

The Activity panel, from the button at the top of the page, says what CC Babysitter did and why.

Reach it from your phone

Open the Claude app on your phone and find the session among your Claude Code sessions. The conversation is all there. Send it a message, and Claude answers from your computer.

On the computer, Open on claude.ai in the card's menu opens the same session in your browser.

Carry on at the computer

When you're back at the computer, the card offers two ways to carry on in a terminal.

Open in Terminal, in the menu beside Back to a terminal, opens a terminal window on the session where it runs. On Windows and Linux it says Open in Windows Terminal or Open in a terminal. The session stays in the background, still babysat and with Remote Control on, and closing that window doesn't stop it.

Back to a terminal ends the background copy, and with it the babysitting. Confirm with End background copy, and you get a command that resumes the session in any terminal. The session moves to Not running on the page. Once you resume it, it shows under Running again, with Remote Control off until you type /rc. Press Babysit if you want it kept alive again.

A babysat session that still runs in its own terminal has an Unbabysit button instead. It stops the babysitting and leaves the session running where it is.
