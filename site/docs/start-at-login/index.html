How-to guide

Start CC Babysitter at login

CC Babysitter brings babysat sessions back only while it runs. Starting it at login means a restart of the computer doesn't end that.

After a restart

When the computer restarts, every app closes, CC Babysitter too. When it starts again at login, it brings your babysat sessions back in the background, as it would after any app closed; otherwise they stay closed until you run ccbabysitter again.

The first time you run ccbabysitter, it turns start at login on for you. After that it leaves the choice to you.

Check whether it's on

On the page, open Settings. The box Start CC Babysitter when I log in shows whether it's on. From a terminal, this shows the same setting, as autostart:

When it's off, the Babysit dialog also offers to turn it on, so the session you babysit survives a restart.

Turn it on or off

Tick or untick the box in Settings, or run:

Use off instead of on to turn it off. Turning it off doesn't stop CC Babysitter: it keeps running until you quit it or restart the computer.

What it uses on each system

  • On macOS, it's a login item. macOS may show a notice saying Background Items Added, and lists CC Babysitter in System Settings under General, then Login Items. If you switch it off there under Allow in the Background, macOS doesn't start it at all, and ccbabysitter tells you so.
  • On Linux, it's a systemd service of your user. On a desktop it starts with your desktop session. On a server it starts at boot and keeps running after you log out.
  • On Windows, it's an entry that starts CC Babysitter's windowless program when you log in, with no console window.

A Mac you reach only over SSH, with nobody logged in at its screen, has nowhere to start a login item. There, ccbabysitter runs in the terminal instead.

Keep the program where it is

Start at login runs the program from where it was when you turned it on. Keep it where the install script put it, or in another folder where it will stay. If you move it, run ccbabysitter from its new place once, and it updates the login entry.
